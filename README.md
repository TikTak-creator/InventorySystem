# StockFlow — система учёта товаров

Десктопное приложение для небольшого магазина: **добавление товаров, изменение цен, продажи, остатки на складе и поиск**.

**Стек:** C# · .NET 8 · WinForms · MySQL (MySqlConnector)

## Возможности

| Раздел | Что умеет |
|---|---|
| **Обзор** | Карточки показателей (товары, выручка и прибыль за сегодня, мало на складе, количество чеков, средний чек), график выручки за 7 дней, последние продажи, список заканчивающихся товаров |
| **Товары** | Каталог, мгновенный поиск (название / артикул / категория), фильтр по категории и «только заканчивающиеся», добавление, редактирование, удаление, приход товара. Расчёт наценки при вводе цен |
| **Продажи** | Окно кассы с корзиной, проверка остатков, оформление чека в транзакции; история чеков за период, состав чека, прибыль по чеку |
| **Склад** | Остатки со статусами (В наличии / Мало / Нет в наличии), стоимость склада, приход, **история изменения цен** по каждому товару |

### Технические детали
- Слоистая архитектура: `Models` → `Data` (репозитории, ADO.NET + параметризованные запросы) → `UI`.
- Продажа выполняется **в одной транзакции** с `SELECT … FOR UPDATE` — остаток не уйдёт в минус даже при одновременной работе нескольких касс.
- В позиции чека сохраняются название, цена продажи и себестоимость на момент продажи — история не ломается при изменении цены или удалении товара.
- Смена цены автоматически пишется в `price_history`.
- База данных и таблицы **создаются автоматически** при первом запуске, плюс демо-данные (16 товаров и продажи за неделю).
- Современный тёмный интерфейс без дизайнера: собственные контролы `Card`, `StatCard`, `BarChart`.

### Горячие клавиши
| Клавиша | Действие |
|---|---|
| `F5` | Обновить текущий раздел |
| `Enter` / двойной клик | Редактировать товар |
| `Delete` | Удалить товар / убрать из корзины |
| `F2` | Оформить продажу (в окне кассы) |

## Запуск

1. Установите **.NET 8 SDK** (или новее) и **MySQL 8** (MySQL Server, XAMPP, OpenServer — подойдёт любой).
2. Укажите логин/пароль MySQL в `InventoryApp/appsettings.json`:
   ```json
   "Default": "Server=localhost;Port=3306;Database=inventory_db;User ID=root;Password=root;CharSet=utf8mb4;"
   ```
   Чтобы не создавать демо-данные — `"SeedDemoData": false`.
3. Запустите:
   ```bash
   cd InventoryApp
   dotnet run
   ```
   или откройте `InventorySystem.slnx` в Visual Studio 2022+ и нажмите **F5**.

База `inventory_db` создастся сама. Скрипт для ручного развёртывания — [`database/schema.sql`](database/schema.sql).

### Сборка exe
```bash
dotnet publish InventoryApp -c Release -r win-x64 --self-contained false -o publish
```

## Структура проекта

```
InventorySystem/
├── InventorySystem.slnx
├── database/
│   └── schema.sql                 # схема БД
└── InventoryApp/
    ├── Program.cs                 # точка входа, инициализация БД
    ├── appsettings.json           # строка подключения
    ├── Models/Models.cs           # Product, Sale, SaleItem, CartItem, PriceChange…
    ├── Data/
    │   ├── Database.cs            # подключение, создание схемы, демо-данные
    │   ├── ProductRepository.cs   # CRUD товаров, приход, история цен
    │   └── SaleRepository.cs      # продажи (транзакции), статистика
    └── UI/
        ├── Theme.cs               # тёмная тема, фабрика контролов
        ├── Controls.cs            # Card, StatCard, BarChart
        ├── MainForm.cs            # главное окно + боковое меню
        ├── Views/                 # Обзор, Товары, Продажи, Склад
        └── Dialogs/               # карточка товара, касса, приход
```
